### Description

The competition is set in the year 2912, where the *Spaceship Titanic*, an interstellar passenger liner carrying nearly 13,000 passengers, collided with a spacetime anomaly. Almost half of the passengers were transported to an alternate dimension. Participants are challenged to predict which passengers were transported by the anomaly using records recovered from the spaceship's damaged computer system. This is a binary classification task (Transported: True/False) and a Getting Started competition designed for learning machine learning basics.

### Evaluation

Submissions are evaluated based on **classification accuracy**, the percentage of predicted labels that are correct.

### Submission File

For each PassengerId in the test set, predict either `True` or `False` for the `Transported` variable. The file should contain a header and have the following format:

```
PassengerId,Transported
0013_01,False
0018_01,False
0019_01,False
0021_01,False
etc.
```

### Dataset Description

The task is to predict whether a passenger was transported to an alternate dimension during the Spaceship Titanic's collision with the spacetime anomaly. Participants are given personal records recovered from the ship's damaged computer system. The training set contains about two-thirds (~8700) of the passengers, and the test set contains the remaining one-third (~4300). Features include the passenger's home planet, cryosleep status, cabin number (formatted as deck/num/side), destination planet, age, VIP status, billing amounts at five luxury amenities (RoomService, FoodCourt, ShoppingMall, Spa, VRDeck), and name. PassengerId takes the form `gggg_pp` where `gggg` indicates a travel group and `pp` is the number within the group. People in a group are often family members, but not always. Passengers in cryosleep are confined to their cabins.
