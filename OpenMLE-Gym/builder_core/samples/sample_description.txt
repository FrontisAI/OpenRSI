### Description

The competition focuses on evaluating the effects of climate change on biodiversity by quantifying the impact of human activities on protected natural areas. A crucial first step is the identification of specific vegetation types, particularly a columnar cactus, in aerial imagery. Participants are challenged to create an algorithm that accurately identifies this cactus from aerial images. 

### Evaluation

Submissions are evaluated on area under the **ROC** curve between the predicted probability and the observed target.

### Submission File

For each id in the test set, predict a probability for the has_cactus variable. The file should contain a header and have the following format:

```
id,has_cactus
1.jpg,0.5
2.jpg,0.5
3.jpg,0.5
etc.
```

### Dataset Description

This dataset consists of numerous 32 x 32 thumbnail images depicting aerial photos of the columnar cactus. The images have been resized for uniformity, with each file name corresponding to its unique ID. Participants must develop a classifier to determine whether an image contains a cactus.
