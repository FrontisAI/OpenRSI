## 2. Dataset Overview

This dataset comprises four instances for counterfactual outcome estimation, spanning causal inference problems in finance, clinical medicine, and neonatal health. Each instance provides observed individuals with a treatment assignment, confounders, a latent noise sample, and a counterfactual treatment assignment. The training data includes both factual and counterfactual outcome labels; the test data provides only the input features.

Three instances (`german_credit`, `ist_aspirin`, `ist_heparin`) use semisynthetic data: real-world features with synthetically generated categorical outcomes determined by a piecewise function of the treatment, confounders, and a discrete latent variable. The fourth instance (`twin_mortality`) uses real-world twin birth data where each twin's observed mortality serves as the counterfactual outcome for their sibling, making the outcomes fully real-valued binary labels.

## 3. File Formats & Schemas

### german_credit

- **Format**: CSV with header, float64 values
- **Content Summary**: Semisynthetic credit risk data with encoded categorical financial features and synthetic 3-valued outcomes.
- **Fields/Columns**:
  - `dig`: (int-valued float) Digitized credit history, values in {0, 1, 2} -- INPUT
  - `Uy`: (int-valued float) Latent noise variable, values in {0, 1, 2, 3, 4, 5, 6} -- INPUT
  - `Existing-Account-Status`: (int-valued float) Treatment variable (current account status), values in {0, 1, 2} -- INPUT
  - `Month-Duration`, `Credit-History`, `Purpose`, `Credit-Amount`, `Saving-Acount`, `Present-Employment`, `Instalment-Rate`, `Sex`, `Guarantors`, `Residence`, `Property`, `Age`, `Installment`, `Housing`, `Existing-Credits`, `Job`, `Num-People`, `Telephone`, `Foreign-Worker`: Encoded financial and demographic covariates -- INPUT
  - `Status`: (int-valued float) Original credit risk label {0, 1} -- INPUT
  - `Existing-Account-Status_prime`: (int-valued float) Counterfactual treatment value -- INPUT
  - `Y`: (int-valued float) Factual synthetic outcome, values in {0, 1, 2} -- TARGET (train only)
  - `Y_prime`: (int-valued float) Counterfactual synthetic outcome, values in {0, 1, 2} -- TARGET (train only)

### ist_aspirin / ist_heparin

- **Format**: CSV with header, float64 values
- **Content Summary**: Semisynthetic stroke trial data with encoded patient features and synthetic 3-valued outcomes. The two instances differ in treatment variable and number of treatment categories.
- **Fields/Columns**:
  - `Ux`: (int-valued float) Discrete latent variable for outcome generation, values in {0, 1, 2, 3, 4, 5, 6} -- INPUT
  - `Uy`: (float) Continuous latent noise variable, sampled from N(0.5, 1/9) -- INPUT
  - `RCONSC`: (int-valued float) Level of consciousness, values in {0, 1, 2} -- INPUT
  - `AGE`: (int-valued float) Binarized age indicator, values in {0, 1} -- INPUT
  - `SEX`: (int-valued float) Sex indicator, values in {0, 1} -- INPUT
  - `DASP14` (aspirin) or `Heparin` (heparin): Treatment variable -- INPUT
    - Aspirin: binary {0, 1}
    - Heparin: 3-valued {0, 1, 2} (none, low dose, medium dose)
  - `DASP14_prime` or `Heparin_prime`: Counterfactual treatment value -- INPUT
  - `Y_3`: (int-valued float) Factual synthetic outcome, values in {0, 1, 2} -- TARGET (train only)
  - `Y_3_prime`: (int-valued float) Counterfactual synthetic outcome, values in {0, 1, 2} -- TARGET (train only)

### twin_mortality

- **Format**: CSV with header, mixed float64/int64 values
- **Content Summary**: Twin birth dataset with 30 maternal and birth covariates, binary treatment assignment (heavier vs lighter twin), and binary mortality outcomes.
- **Fields/Columns**:
  - `adequacy`, `nprevist`, `mpcb`, `resstatb`, `dmar`, `dmeduc`, `dmage`, `gestat`, `pldel`, `wtgain`, `drink`, `cigar`, `othermr`, `uterine`, `rh`, `renal`, `preterm`, `pre4000`, `incervix`, `eclamp`, `phyper`, `chyper`, `hemo`, `hydra`, `herpes`, `diabetes`, `lung`, `cardiac`, `anemia`, `dtotord`: 30 maternal health and birth covariates -- INPUT
  - `X`: (int) Treatment assignment (1 = heavier twin, 0 = lighter twin) -- INPUT
  - `X_prime`: (int) Counterfactual treatment (1 - X) -- INPUT
  - `Uy`: (float) Continuous latent noise variable, sampled from N(1, 2/3) -- INPUT
  - `Y`: (float) Factual mortality outcome (1 = died within 1 year, 0 = survived) -- TARGET (train only)
  - `Y_prime`: (float) Counterfactual mortality outcome -- TARGET (train only)

## 4. Special Notes

- All values in the CSV files are numeric. Categorical features have been pre-encoded to integer values.
- The `x_test.csv` files contain all columns present in `train.csv` except the outcome columns (Y/Y_prime or Y_3/Y_3_prime).
- The outcome columns in `train.csv` are order-aligned with the input features: each row's outcomes correspond to the features in the same row.
- For the semisynthetic instances (`german_credit`, `ist_aspirin`, `ist_heparin`), the latent variables (`Uy`, `Ux`) are included as input features because they are part of the causal model structure. The model is expected to use these to infer the latent state for counterfactual estimation.
- For `twin_mortality`, the binary outcomes represent real mortality events (died within 1 year = 1). The treatment assignment `X` is generated via a logistic model over covariates, not from the original data.

## 5. Empirical EDA Addendum

| Instance | Train / test rows | Factual treatment counts | Factual outcome counts | Rows whose counterfactual outcome changes | Largest standardized train/test mean shift |
|---|---:|---|---|---:|---:|
| `german_credit` | 1,400 / 600 | 0: 555; 1: 382; 2: 463 | 0: 605; 1: 380; 2: 415 | 38.79% | 0.085 |
| `ist_aspirin` | 4,428 / 1,899 | 0: 1,993; 1: 2,435 | 0: 2,190; 1: 757; 2: 1,481 | 18.59% | 0.030 |
| `ist_heparin` | 4,828 / 2,070 | 0: 2,311; 1: 1,392; 2: 1,125 | 0: 2,144; 1: 844; 2: 1,840 | 26.97% | 0.052 |
| `twin_mortality` | 7,980 / 3,420 | 0: 4,001; 1: 3,979 | survived: 6,572; died: 1,408 | 10.01% | 0.067 |

There are no missing values in any visible train or test table, and every row uses a counterfactual treatment different from its factual treatment. No exact input row is shared between train and test. The standardized mean shifts are small overall, but German credit shows the strongest outcome response to treatment changes and the largest distribution shift, while twin mortality has a 17.64% factual mortality rate and only a 10.01% factual/counterfactual outcome-change rate.

These are paired potential-outcome tasks, not ordinary outcome prediction: validation should score both factual and counterfactual outputs and preserve the row-wise treatment/counterfactual-treatment pairing. Because most features are numerically encoded categories, categorical support checks are more meaningful than assuming continuous geometry from the stored numeric type.
