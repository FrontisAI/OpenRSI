# Data Description

## 1. Directory Structure

```
problem/data/
├── simulated_layered_growth/
│   └── data.h5ad                # 3,000 cells × 500 genes, simulated layered tissue growth
├── simulated_radial_growth/
│   └── data.h5ad                # 12,000 cells × 500 genes, simulated radial tissue growth
├── brain_cortex/
│   └── data.h5ad                # 2,525 cells × 200 genes, E15 mouse cerebral cortex (Slide-seq v2)
├── gut_e13_5/
│   └── data.h5ad                # 2,381 bins × 2,000 genes, E13.5 mouse gut (Stereo-seq)
├── lung_e13_5/
│   └── data.h5ad                # 1,030 bins × 606 genes, E13.5 mouse lung (Stereo-seq)
└── thymus/
    └── data.h5ad                # 2,165 spots × 100 genes, postnatal human thymus (10x Visium)
```

## 2. Dataset Overview

This dataset comprises six spatial transcriptomic datasets stored as AnnData `.h5ad` files. Each file contains spliced and unspliced RNA count matrices together with 2D spatial coordinates for every cell (or spatial bin/spot). The datasets span two simulated tissue growth scenarios and four real tissues profiled with different spatial transcriptomic technologies.

The two simulated datasets (layered growth and radial growth) contain synthetically generated spliced and unspliced count matrices with known spatial coupling. The four real datasets represent preprocessed spatial transcriptomic measurements from mouse brain cortex, mouse gut, mouse lung, and human thymus, each profiled with a different spatial technology (Slide-seq v2, Stereo-seq, or 10x Visium). Real datasets include additional preprocessing outputs such as smoothed count matrices (Ms/Mu), PCA embeddings, KNN graphs, and spatial neighbor graphs. Cell type annotations are provided for all real datasets via a `clusters` column in the observation metadata.

All six instances are independent of one another and share no data or parameters.

## 3. File Formats & Schemas

Each instance contains a single AnnData `.h5ad` file (`data.h5ad`) with the following general structure. Fields vary by instance as noted below.

### Simulated Instances (simulated_layered_growth, simulated_radial_growth)

- **Format**: AnnData HDF5 (`.h5ad`)
- **Content Summary**: Simulated spatial transcriptomic data with spliced and unspliced RNA counts and 2D spatial coordinates. No cell annotations or preprocessing artifacts.

| Field | Type | Description |
|-------|------|-------------|
| `X` | Dense float64 matrix (n_cells × n_genes) | Spliced count matrix (same content as `layers['spliced']` but in dense format) — INPUT |
| `layers['spliced']` | Sparse CSR float64 | Spliced RNA counts per cell per gene — INPUT |
| `layers['unspliced']` | Sparse CSR float64 | Unspliced RNA counts per cell per gene — INPUT |
| `obsm['X_spatial']` | Dense float64 (n_cells × 2) | 2D spatial coordinates for each cell — INPUT |

- **simulated_layered_growth**: 3,000 cells, 500 genes
- **simulated_radial_growth**: 12,000 cells, 500 genes

### Real Instances (brain_cortex, gut_e13_5, lung_e13_5, thymus)

- **Format**: AnnData HDF5 (`.h5ad`)
- **Content Summary**: Preprocessed spatial transcriptomic data with raw and smoothed count matrices, spatial coordinates, spatial neighbor graphs, dimensionality reductions, and cell type annotations.

**Common fields across all real instances:**

| Field | Type | Description |
|-------|------|-------------|
| `X` | Sparse matrix (n_cells × n_genes) | Normalized/filtered count matrix — INPUT |
| `layers['spliced']` | Sparse int64 | Raw spliced RNA counts — INPUT |
| `layers['unspliced']` | Sparse int64 | Raw unspliced RNA counts — INPUT |
| `layers['Ms']` | Dense float32 | First-order moment (smoothed) spliced counts — INPUT |
| `layers['Mu']` | Dense float32 | First-order moment (smoothed) unspliced counts — INPUT |
| `obsm['X_spatial']` | Dense float64 (n_cells × 2) | 2D spatial coordinates — INPUT |
| `obsm['X_pca']` | Dense float32 (n_cells × 30) | PCA embedding — INPUT |
| `obsp['spatial_graph']` | Sparse CSR (n_cells × n_cells) | Spatial neighbor graph — INPUT |
| `obsp['connectivities']` | Sparse CSR (n_cells × n_cells) | KNN connectivities in gene expression space — INPUT |
| `obsp['distances']` | Sparse CSR (n_cells × n_cells) | KNN distances in gene expression space — INPUT |
| `obs['clusters']` | Categorical | Cell type annotation — INPUT |

**Instance-specific details:**

- **brain_cortex** (2,525 cells, 200 genes): Mouse E15 cerebral cortex. Cell types: VZ (325), SVZ (957), IZ (62), CP (516), L5/6 (610), CR Cells (55). Additional embeddings: `obsm['X_umap']` (UMAP), `obsm['X_pos']` (alternate spatial embedding).

- **gut_e13_5** (2,381 bins, 2,000 genes): Mouse E13.5 gut at 20-um spatial bin resolution. Cell types: Mesenchymal (2,093), Epithelial (288). Additional layer: `layers['count']` (raw total counts). Observation metadata includes 508 regulon activity scores (`Regulon - *` columns) and module activity scores from gene regulatory network analysis.

- **lung_e13_5** (1,030 bins, 606 genes): Mouse E13.5 lung at 20-um spatial bin resolution. Cell types: Mesenchymal (700), Epithelial (330). Same additional fields as gut (raw counts layer, regulon/module activity scores).

- **thymus** (2,165 spots, 100 genes): Human postnatal thymus. Cell types: Cortex (1,497), Medulla (483), Edge (185). Additional layer: `layers['ambiguous']` (ambiguously mapped reads). Observation metadata includes extensive sample-level annotations (donor information, tissue processing parameters, spatial array coordinates) and deconvolution-derived cell type abundance estimates for approximately 50 fine-grained immune and stromal cell types.

### Variable Metadata (var)

- **Simulated instances**: No variable-level metadata.
- **Real instances**: `var` contains columns `means`, `dispersions`, `dispersions_norm`, and `highly_variable` from the gene selection preprocessing step.

## 4. Special Notes

- The `X` matrix in the simulated instances is dense float64 and contains the same data as `layers['spliced']`. In real instances, `X` is sparse and represents normalized/filtered counts that may differ from the raw `layers['spliced']`.
- The Stereo-seq datasets (gut_e13_5, lung_e13_5) use spatial bins rather than single cells. Each observation corresponds to a 20-um spatial bin that may aggregate transcripts from multiple cells.
- The spatial graph (`obsp['spatial_graph']`) in real instances encodes spatial neighbor relationships computed from `obsm['X_spatial']` coordinates. The KNN graphs (`obsp['connectivities']`, `obsp['distances']`) are computed in gene expression space, not spatial space.
- The regulon and module activity columns in gut_e13_5 and lung_e13_5 are derived from gene regulatory network inference on the same expression data and are provided as additional features.
- The thymus dataset contains many sample-level metadata columns (donor demographics, sequencing parameters, array coordinates) that describe experimental provenance rather than per-spot biological measurements.

## 5. Empirical EDA Addendum

The following statistics were computed from the six visible `data.h5ad` files only.

| Instance | Observations × genes | `X` density | Raw spliced / unspliced density | Median spatial nearest-neighbor distance | Visible annotation balance |
|---|---:|---:|---:|---:|---|
| `simulated_layered_growth` | 3,000 × 500 | 0.2270 | 0.2270 / 0.2167 | 0.0083 | No biological labels |
| `simulated_radial_growth` | 12,000 × 500 | 0.2216 | 0.2216 / 0.2122 | 0.0083 | No biological labels |
| `brain_cortex` | 2,525 × 200 | 0.2037 | 0.1308 / 0.0966 | 10.1184 | Six regions; SVZ is largest (957), CR Cells smallest (55) |
| `gut_e13_5` | 2,381 × 2,000 | 0.3241 | 0.2732 / 0.0435 | 25.0 | 2,093 mesenchymal and 288 epithelial bins |
| `lung_e13_5` | 1,030 × 606 | 0.4457 | 0.3595 / 0.0840 | 25.0 | 700 mesenchymal and 330 epithelial bins |
| `thymus` | 2,165 × 100 | 0.2512 | 0.2512 / 0.1646 | 99.6717 | 1,497 cortex, 483 medulla, 185 edge spots |

The real datasets' spatial graphs average approximately 30, 8, 16, and 6.1 neighbors per observation for brain, gut, lung, and thymus, respectively. These differences reflect both assay geometry and preprocessing; graph degree and coordinate scale should therefore be handled per instance. The smoothed `Ms`/`Mu` layers are far denser than the raw spliced/unspliced layers, so they should not be treated as interchangeable measurements. Region labels are useful for stratified diagnostics but are inputs, not prediction targets.
