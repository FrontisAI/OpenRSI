## 2. Dataset Overview

This dataset contains simulated single-molecule localization microscopy (SMLM) point clouds for spatial clustering evaluation. Each file represents one field of view (FOV) containing 2D molecular localizations in a nominal 2000 x 2000 nm region. The localizations consist of both clustered molecules (assigned to numbered clusters) and background (non-clustered) molecules.

The four instances represent different clustering scenarios with varying complexity:

- **scenario_8_no_blinking**: 20 clusters with two different densities (10 clusters of 5 molecules and 10 clusters of 15 molecules), 50% of total molecules clustered. Approximately 400 localizations per FOV.
- **scenario_8_blinking**: Same cluster configuration as above but with simulated fluorophore blinking (each molecule produces 4-5 localizations on average), resulting in approximately 1,500 localizations per FOV.
- **scenario_5_blinking**: 100 clusters of 15 molecules each, 50% clustered, with blinking. Higher cluster density with approximately 12,000 localizations per FOV.
- **scenario_6_blinking**: 20 elliptically shaped clusters (aspect ratio 3:1), 50 molecules each, 50% clustered, with blinking. Approximately 7,500 localizations per FOV.

Each instance provides 3 training FOVs (with ground truth cluster labels) and 47 test FOVs (coordinates only).

## 3. File Formats & Schemas

### Training CSV Files (`train/*.csv`)
- **Format**: CSV with header row
- **Content Summary**: Complete point cloud data with ground truth cluster assignments for training.
- **Fields/Columns**:
  - `x`: float64 -- X coordinate of the localization in nanometers (range approximately 0-2000). INPUT
  - `y`: float64 -- Y coordinate of the localization in nanometers (range approximately 0-2000). INPUT
  - `index`: int64 -- Ground truth cluster assignment. 0 indicates background (non-clustered), positive integers (1, 2, ..., N) indicate cluster membership. TARGET

### Test CSV Files (`test/*.csv`)
- **Format**: CSV with header row
- **Content Summary**: Point cloud coordinates only, without cluster labels.
- **Fields/Columns**:
  - `x`: float64 -- X coordinate of the localization in nanometers. INPUT
  - `y`: float64 -- Y coordinate of the localization in nanometers. INPUT

### Configuration File (`train/metadata.json`)
- **Format**: JSON
- **Content Summary**: Training configuration for all benchmark scenarios, including training FOV indices, data augmentation parameters, and DBSCAN baseline parameters. Shared across all instances.
- **Key Fields** (per scenario entry):
  - `training_indices`: list of int -- FOV indices used for training (1-based)
  - `builder_kwargs`: dict -- Data augmentation parameters (dataset_size, noise_point_range, cluster_count_range, connectivity_radius, etc.)
  - `recurrent_iterations`: int -- Number of iterative processing steps in the training configuration
  - `optimized_DBSCAN_params`: dict -- Fine-tuned DBSCAN parameters (`eps`, `min_samples`)
  - `DBSCAN_params`: dict -- Baseline DBSCAN parameters (`eps`, `min_samples`)

## 4. Special Notes

- The training FOVs contain full information (coordinates + cluster labels), while test FOVs contain only coordinates. The number of localizations per FOV varies slightly across FOVs within the same instance.
- The `index` column in training files uses 0 for background and positive integers for cluster IDs. Background localizations typically constitute approximately 50% of all points.
- The `metadata.json` file contains entries for many scenarios beyond the four included here. Its human-readable scenario labels do not exactly equal the four directory names, so configuration mapping should be established from scenario semantics rather than string equality alone.
- File naming conventions differ slightly across instances (e.g., `diffden_DetectionList1.csv` without underscore before the index in scenario_8_blinking vs. `diffden_MoleculeList_1.csv` with underscore in scenario_8_no_blinking).

## 5. Empirical EDA Addendum

| Scenario | Train / test FOVs | Points per train FOV | Points per test FOV | Mean training background | Positive clusters per training FOV | Median nearest-neighbor distance, train / test |
|---|---:|---:|---:|---:|---:|---:|
| `scenario_5_blinking` | 3 / 47 | 11,311–11,969 | 11,168–12,103 | 49.82% | 100 | 5.48 / 5.51 nm |
| `scenario_6_blinking` | 3 / 47 | 7,529–8,117 | 7,352–8,356 | 50.56% | 20 | 5.38 / 5.43 nm |
| `scenario_8_blinking` | 3 / 47 | 1,530–1,673 | 1,341–1,755 | 48.79% | 20 | 6.98 / 7.17 nm |
| `scenario_8_no_blinking` | 3 / 47 | 400 | 400 | 50.00% | 20 | 24.84 / 26.32 nm |

Train and test point-count and nearest-neighbor distributions are broadly consistent within each scenario, but density differs by almost 30-fold across scenarios. This supports per-scenario clustering scales rather than one global radius. Blinking creates multiple localizations per molecule and correspondingly much shorter nearest-neighbor distances; training cluster sizes therefore describe localization counts, not necessarily unique molecule counts.

Across all 50 no-blinking FOVs, 169 individual coordinate values lie just outside the nominal [0, 2,000] range; the other three scenarios have none. Coordinates should not be clipped or discarded without an explicit modeling reason. Only the 12 training CSVs contain cluster labels; all statistics involving background or cluster size use those visible labeled files only.
