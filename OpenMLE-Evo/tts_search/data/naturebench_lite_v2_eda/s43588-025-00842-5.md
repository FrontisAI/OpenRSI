# Data Description

## 1. Directory Structure

```
problem/data/zeolite_osda_binding/
├── train_data.csv              # Training data: 552,879 framework-molecule binding pairs (68 columns)
├── x_test.csv                  # Test inputs: 61,384 framework-molecule pairs (17 columns, no targets)
├── osda_priors_0.pkl           # Pre-computed molecular descriptors (2,974 molecules x 1,667 features)
├── zeolite_priors_0.pkl        # Pre-computed framework descriptors (216 zeolites x 1,948 features)
└── splits/
    ├── 1/
    │   ├── smiles_train.npy    # Training SMILES for ensemble split 1 (2,360 SMILES)
    │   └── smiles_val.npy      # Validation SMILES for ensemble split 1 (315 SMILES)
    ├── 2/                      # Split 2 (train: 2,388, val: 287)
    ├── 3/                      # Split 3 (train: 2,390, val: 285)
    ├── 4/                      # Split 4 (train: 2,391, val: 284)
    └── 5/                      # Split 5 (train: 2,370, val: 305)
```

## 2. Dataset Overview

This dataset contains framework-molecule binding affinity data derived from force-field docking simulations of organic molecules in zeolite frameworks. Each record represents a unique pairing of one molecule (identified by SMILES) with one zeolite framework (identified by its three-letter framework type code). The dataset covers 2,974 distinct molecules and 216 experimentally known zeolite frameworks.

The training set contains 552,879 pairs with three prediction targets: a binary binding label indicating whether the molecule fits inside the framework cavities, a continuous binding energy measuring the interaction strength in kJ/mol/Si, and a discrete loading classification indicating the normalized number of molecules per unit cell. The test set contains 61,384 pairs (299 molecules across 216 frameworks) for which only pair identifiers and auxiliary metadata are provided.

Five ensemble train/validation splits are provided under `splits/`, each defined by SMILES-level partitioning. All five splits share the same held-out test molecules (the 299 molecules in x_test.csv). Each split assigns the remaining molecules to different train/validation subsets, enabling ensemble model training with varied validation sets.

## 3. File Formats & Schemas

### train_data.csv

- **Format**: CSV with header row
- **Rows**: 552,879 (one per framework-molecule pair)
- **Content Summary**: Training pairs with identifiers, auxiliary metadata, and prediction targets.

**Identifier Columns**:
- `SMILES`: string, canonical SMILES representation of the molecule
- `Zeolite`: string, three-letter zeolite framework type code (e.g., "ABW", "CHA", "MFI")

**Auxiliary Metadata Columns**:
- `crystal_id`: float64, crystal structure identifier (NaN for non-binding pairs)
- `affinity`: float64, affinity index (NaN for non-binding pairs)
- `complex`: int64, complex identifier
- `InchiKey`: string, InChI key of the molecule
- `Ligand formula`: string, molecular formula
- `ligand_stoichiometry`: string, stoichiometric formula
- `pose_formula`: string, formula of the docked complex (NaN for non-binding)
- `constant_vol`: mixed, whether docking used constant volume
- `substrate_unit_cell`: int64, number of Si atoms in the unit cell
- `dock_config`: string, docking configuration used
- `ligand_atoms`: int64, number of atoms in the ligand
- `all_ligand_atoms`: float64, total ligand atoms in the complex
- `pose_atoms`: float64, total atoms in the docked pose
- `substrate_atoms`: float64, number of framework atoms
- `nonisomeric_inchikey`: string, InChI key without stereochemistry

**Target Columns**:
- `b`: int64 (0 or 1) -- TARGET, binary binding label (1 = binding, 0 = non-binding)
- `Binding (SiO2)`: float64 -- TARGET, binding energy in kJ/mol/Si (0.0 for non-binding pairs, negative for binding pairs; range approximately [-29.83, 0.0])
- `load_norm_class`: int64 (0-47) -- TARGET, discrete loading classification index (48 classes)
- `load_norm_0` through `load_norm_47`: int64 (0 or 1) -- TARGET, one-hot encoding of loading class

### x_test.csv

- **Format**: CSV with header row
- **Rows**: 61,384 (one per test framework-molecule pair)
- **Content Summary**: Test pair identifiers and auxiliary metadata only (no target columns).
- **Fields**: Same identifier and auxiliary metadata columns as train_data.csv (`SMILES`, `Zeolite`, `crystal_id`, `affinity`, `complex`, `InchiKey`, `Ligand formula`, `ligand_stoichiometry`, `pose_formula`, `constant_vol`, `substrate_unit_cell`, `dock_config`, `ligand_atoms`, `all_ligand_atoms`, `pose_atoms`, `substrate_atoms`, `nonisomeric_inchikey`).

### osda_priors_0.pkl

- **Format**: Python pickle file containing a pandas DataFrame
- **Shape**: 2,974 rows x 1,667 columns
- **Content Summary**: Pre-computed molecular descriptors for all 2,974 molecules. The DataFrame is indexed by SMILES strings.
- **Feature Groups**: Includes molecular weight, volume, asphericity, eccentricity, WHIM descriptors, GETAWAY descriptors, Morgan fingerprint bits, and Morse-type molecular shape descriptors. Feature names include `mol_weight`, `mol_volume`, `asphericity`, `eccentricity`, `whim_*`, `getaway_*`, `morgan_*`, `morse_*`, among others.

### zeolite_priors_0.pkl

- **Format**: Python pickle file containing a pandas DataFrame
- **Shape**: 216 rows x 1,948 columns
- **Content Summary**: Pre-computed framework descriptors for all 216 zeolite frameworks. The DataFrame is indexed by framework type codes (e.g., "ABW", "CHA").
- **Feature Groups**: Includes unit cell parameters (`a`, `b`, `c`, `alpha`, `beta`, `gamma`), pore size distribution histograms, stochastic ray tracing histograms, physical properties, and ring size counts. Feature names include `psd_*`, `ray_*`, `ring_size_*`, among others.

### splits/{1-5}/smiles_train.npy, smiles_val.npy

- **Format**: NumPy binary files containing 1D arrays of SMILES strings
- **Content Summary**: Five different train/validation partitions of the non-test molecules for ensemble training. Each split assigns molecules to training (2,360-2,391 SMILES) and validation (284-315 SMILES) subsets.
- **Usage**: Filter train_data.csv by SMILES membership to obtain train/validation subsets for each ensemble model.

## 4. Special Notes

- Non-binding pairs (b=0) have `Binding (SiO2)` = 0.0 and `load_norm_class` = 0. For binding pairs (b=1), `Binding (SiO2)` is negative (stronger binding = more negative), and `load_norm_class` ranges from 0 to 47.
- The molecular descriptor DataFrame (`osda_priors_0.pkl`) covers all 2,974 molecules including both training and test molecules. Similarly, `zeolite_priors_0.pkl` covers all 216 frameworks. To obtain features for a specific pair, look up the molecule's SMILES in `osda_priors_0.pkl` and the framework code in `zeolite_priors_0.pkl`.
- The dataset was split at the SMILES level (by stereoisomers), not at the pair level. All pairs involving a given molecule belong to the same split.
- The `load_norm_class` column contains 48 discrete classes (0-47). The one-hot columns `load_norm_0` through `load_norm_47` correspond to these classes.

## 5. Empirical EDA Addendum

The visible pair tables and descriptor resources were checked jointly.

| Resource | Empirical coverage and distribution |
|---|---|
| Training pairs | 552,879 rows; 2,675 molecules; all 216 frameworks; 320,002 binding pairs (57.88%) |
| Test pairs | 61,384 rows; 299 molecules; all 216 frameworks; zero molecule overlap with training |
| Molecular descriptors | 2,974 molecules × 1,667 columns; no missing cells; all train and test molecules covered |
| Framework descriptors | 216 frameworks × 1,948 columns; no missing cells; 28 constant numeric columns |

Binding energy has median -2.646 kJ/mol/Si across all training pairs and median -6.725 among binding pairs; its full range is -29.827 to 0. Non-binding pairs account for 232,877 rows and deterministically carry zero energy and loading class 0. The 48 loading classes are extremely imbalanced, with several classes represented by fewer than ten rows, so hierarchical or masked treatment of the three targets may be preferable to a flat 48-class objective.

Each of the five supplied SMILES splits has no train–validation overlap and no overlap with the 299 test molecules. Frameworks are fully reused while molecules are held out, so the central generalization problem is molecular extrapolation conditioned on known framework descriptors. Descriptor scaling and constant-column removal must be fitted inside each molecule-level training split.
