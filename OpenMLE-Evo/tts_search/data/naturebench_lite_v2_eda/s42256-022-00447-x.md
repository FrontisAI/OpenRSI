## 2. Dataset Overview

This dataset encompasses 13 molecular property prediction benchmarks from the MoleculeNet benchmark suite, spanning both classification and regression tasks across diverse chemical and biophysical domains. Each instance directory contains data for a single benchmark dataset.

All instances share a common pre-training corpus (`pubchem-10m-clean.txt`) containing approximately 10 million unique molecular SMILES strings sampled from PubChem. This large unlabeled corpus is intended to support self-supervised or unsupervised molecular representation learning prior to fine-tuning on the individual benchmark tasks.

The 13 benchmarks divide into two groups by task type. Seven are binary classification tasks measuring biological activity or toxicity properties: BACE (beta-secretase 1 inhibition), BBBP (blood-brain barrier penetration), ClinTox (clinical trial toxicity), HIV (replication inhibition), MUV (maximum unbiased validation bioassays across 17 targets), SIDER (side effect categories across 27 system organ classes), and Tox21 (toxicity across 12 biological targets). Six are regression tasks predicting physicochemical or quantum-mechanical properties: ESOL (aqueous solubility), FreeSolv (hydration free energy), Lipo (lipophilicity), QM7 (atomization energy), QM8 (electronic spectra properties across 12 targets), and QM9 (8 quantum mechanics properties). All classification benchmarks use scaffold-based splitting. Regression benchmarks also use scaffold splitting except QM9, which uses random splitting.

## 3. File Formats & Schemas

### Pre-training Corpus (`pubchem-10m-clean.txt`)

- **Format**: Plain text, one SMILES string per line
- **Content Summary**: ~9,999,918 unique molecular SMILES strings from PubChem, suitable for large-scale unsupervised pre-training
- **Size**: ~442 MB

### Classification Benchmarks (train.csv, valid.csv)

All classification benchmarks share a common structure: a `smiles` column (INPUT) and one or more binary target columns (TARGET, values 0 or 1). Multi-task benchmarks may have missing values (empty cells) indicating the molecule was not tested for that particular target.

**BBBP**: Columns: `num` (row index), `name` (molecule name), `p_np` (TARGET: 1 = penetrates, 0 = non-penetrating), `smiles` (INPUT).

**Tox21**: Columns: 12 binary target columns (`NR-AR`, `NR-AR-LBD`, `NR-AhR`, `NR-Aromatase`, `NR-ER`, `NR-ER-LBD`, `NR-PPAR-gamma`, `SR-ARE`, `SR-ATAD5`, `SR-HSE`, `SR-MMP`, `SR-p53`) (TARGET), `mol_id` (identifier), `smiles` (INPUT). Many target values are missing (NaN).

**ClinTox**: Columns: `smiles` (INPUT), `FDA_APPROVED` (TARGET), `CT_TOX` (TARGET: clinical toxicity).

**HIV**: Columns: `smiles` (INPUT), `activity` (text label: CI/CA/CM), `HIV_active` (TARGET: binary).

**BACE**: Columns: `smiles` (INPUT), `CID` (compound identifier), `Class` (TARGET: binary binding label), `Model`, `pIC50`, plus ~590 molecular descriptor columns (MW, AlogP, HBA, HBD, RB, topological indices, E-state descriptors, etc.).

**SIDER**: Columns: `smiles` (INPUT), plus 27 binary side-effect target columns corresponding to MedDRA system organ classes (TARGET).

**MUV**: Columns: 17 binary bioassay target columns (`MUV-466` through `MUV-859`) (TARGET), `mol_id` (identifier), `smiles` (INPUT). Extremely sparse -- most target values are missing.

### Regression Benchmarks (train.csv, valid.csv)

**FreeSolv**: Columns: `iupac` (molecule IUPAC name), `smiles` (INPUT), `expt` (TARGET: experimental hydration free energy in kcal/mol), `calc` (calculated solvation energy).

**ESOL**: Columns: `Compound ID`, `ESOL predicted log solubility in mols per litre`, `Minimum Degree`, `Molecular Weight`, `Number of H-Bond Donors`, `Number of Rings`, `Number of Rotatable Bonds`, `Polar Surface Area`, `measured log solubility in mols per litre` (TARGET), `smiles` (INPUT).

**Lipo**: Columns: `CMPD_CHEMBLID` (compound ChEMBL identifier), `exp` (TARGET: experimental lipophilicity, logD at pH 7.4), `smiles` (INPUT).

**QM7**: Columns: `smiles` (INPUT), `u0_atom` (TARGET: atomization energy in kcal/mol).

**QM8**: Columns: `smiles` (INPUT), plus 12 electronic spectra property columns (TARGET): `E1-CC2`, `E2-CC2`, `f1-CC2`, `f2-CC2`, `E1-PBE0`, `E2-PBE0`, `f1-PBE0`, `f2-PBE0`, `E1-CAM`, `E2-CAM`, `f1-CAM`, `f2-CAM`.

**QM9**: Columns: `mol_id` (identifier), `smiles` (INPUT), `A`, `B`, `C` (rotational constants), `mu` (TARGET: dipole moment), `alpha` (TARGET: isotropic polarizability), `homo` (TARGET: HOMO energy), `lumo` (TARGET: LUMO energy), `gap` (TARGET: HOMO-LUMO gap), `r2` (TARGET: electronic spatial extent), `zpve` (TARGET: zero-point vibrational energy), `cv` (TARGET: heat capacity at 298.15K), plus additional thermodynamic energy columns (`u0`, `u298`, `h298`, `g298`, `u0_atom`, `u298_atom`, `h298_atom`, `g298_atom`).

### Test Input Files (x_test.csv)

Each instance's `x_test.csv` contains only the input features for the test set molecules. The `smiles` column is always present and serves as the molecular identifier for alignment. Auxiliary columns (identifiers, molecular descriptors) are retained where applicable, but all target/label columns have been removed.

## 4. Special Notes

- Multi-task classification benchmarks (Tox21, MUV, SIDER, ClinTox) contain multiple target columns per molecule. Missing values (NaN) are common in Tox21 and MUV, indicating the molecule was not assayed for that target.
- The `smiles` column serves as the primary identifier across all instances. Predictions must be aligned with the `smiles` column in `x_test.csv`.
- The BACE dataset includes ~590 pre-computed molecular descriptor columns in addition to SMILES. These are auxiliary features available for use but not required.
- QM9 target properties span different physical units and magnitudes: dipole moment (Debye), polarizability (Bohr^3), energies (Hartree), electronic spatial extent (Bohr^2), and heat capacity (cal/mol/K).
- The `pubchem-10m-clean.txt` file is identical across all instances and represents a large-scale pre-training resource. All valid SMILES strings have been pre-filtered for RDKit parseability.

## 5. Empirical EDA Addendum

The 13 benchmarks are statistically heterogeneous even when they share the same SMILES interface.

| Data characteristic | Empirical finding |
|---|---|
| Single-task classification | BACE positive rate 42.56%; BBBP 82.22%; HIV 3.75% |
| ClinTox | `FDA_APPROVED` is 93.32% positive, while `CT_TOX` is 8.03% positive |
| MUV | 75.36% of training cells are missing; observed positive rates are only 0.15–0.22% across 17 assays |
| Tox21 | 11,519 training target cells are missing; observed positive rates range from 2.49% to 14.89% |
| SIDER | No missing training labels, but positive rates across 27 targets range from 1.40% to 91.32% |
| Regression scale | Training medians are -2.619 for ESOL, -3.130 for FreeSolv, 2.340 for Lipo, and -1,559.34 for QM7; multi-target QM8/QM9 also mix scales |

Exact SMILES sets are disjoint among train, validation, and test for every benchmark except QM9, where 17 train–validation and 15 train–test SMILES overlap. This is consistent with QM9's random rather than scaffold split, but exact-structure leakage should be considered when interpreting validation. QM7, QM8, and QM9 also contain a small number of repeated SMILES within labeled splits despite mostly unique rows.

The first visible PubChem corpus contains 9,999,918 lines; SMILES lengths have 10th/50th/90th percentiles of 27/40/65 characters. The 13 copies have the same full SHA-256 digest and are byte-identical, so they constitute one shared pretraining corpus, so they should be cached once rather than repeatedly scanned. Multi-task losses and metrics must mask missing labels per target, and target normalization should be learned separately for every regression endpoint.
