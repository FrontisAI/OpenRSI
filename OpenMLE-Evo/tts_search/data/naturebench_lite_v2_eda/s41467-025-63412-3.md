## 1. Directory Structure


## 2. Dataset Overview

This dataset covers two prediction tasks in the lasso peptide domain of ribosomally synthesized and post-translationally modified peptides (RiPPs). Lasso peptides adopt a unique threaded lariat knot conformation formed by a lasso cyclase enzyme, conferring diverse bioactivities and remarkable stability. Predicting lasso peptide properties from sequence data is challenging due to limited experimental data and the complexity of substrate fitness landscapes.

The first instance (`cyclase_peptide_pair`) addresses the prediction of whether a given lasso cyclase enzyme is compatible with a given lasso peptide substrate. The dataset contains cyclase-peptide sequence pairs labeled as compatible (natural pairs) or incompatible (synthetically mismatched pairs). The second instance (`ubonodin_rnap_inhibition`) addresses the prediction of RNA polymerase (RNAP) inhibitory activity for variants of the lasso peptide ubonodin, where each variant has a continuous enrichment score that estimates inhibitory activity.

Both instances share RODEO-predicted lasso precursor peptide sequences (`RODEO_seq_high_score.xlsx`) that can be used for domain-adaptive pretraining of protein language models. The RODEO data provides 7701 non-redundant high-scoring lasso precursor peptide entries (4485 unique core sequences) drawn from genomic analyses.

## 3. File Formats & Schemas

### cyclase_peptide_pair/train.csv and val.csv

- **Format**: CSV with header
- **Content Summary**: Labeled cyclase-peptide pairs for training (9238 samples) and validation (1980 samples).
- **Fields/Columns**:
  - `Cyclase sequence`: (str) Amino acid sequence of the lasso cyclase enzyme (80-1013 residues) -- INPUT
  - `Core`: (str) Amino acid sequence of the lasso peptide core (7-225 residues) -- INPUT
  - `label`: (int) Binary compatibility label: 1 = compatible (natural) pair, 0 = incompatible (mismatched) pair -- TARGET

### cyclase_peptide_pair/test_input.csv

- **Format**: CSV with header
- **Content Summary**: Unlabeled cyclase-peptide pairs for prediction (1980 samples).
- **Fields/Columns**:
  - `Cyclase sequence`: (str) Amino acid sequence of the lasso cyclase enzyme (137-755 residues) -- INPUT
  - `Core`: (str) Amino acid sequence of the lasso peptide core (8-225 residues) -- INPUT

### cyclase_peptide_pair/Cyclase_peptide_data_RODEO.xlsx

- **Format**: Excel spreadsheet (.xlsx)
- **Content Summary**: RODEO-predicted lasso cyclase-peptide pair annotations with biological metadata (7160 entries).
- **Key Fields/Columns**:
  - `Accession_id`: (str) NCBI accession identifier
  - `Cyclase sequence`: (str) Amino acid sequence of the cyclase
  - `Core`: (str) Amino acid sequence of the lasso peptide core
  - `Leader`: (str) Leader peptide sequence
  - `Genus/Species`: (str) Source organism
  - `Lasso Score`: (float) RODEO prediction confidence score
  - `Acceptor site`: (int) Position of the acceptor residue in the core
  - `Acceptor residue`: (str) Identity of the acceptor residue (D or E)

### pretraining_data/RODEO_seq_high_score.xlsx (shared across both instances)

- **Format**: Excel spreadsheet (.xlsx)
- **Content Summary**: High-scoring lasso precursor peptide entries from RODEO genomic analysis (7701 entries, 4485 unique core sequences). Contains 186 columns including sequence information, structural features, scoring motifs, and compositional descriptors.
- **Key Fields/Columns**:
  - `Query accession ID`: (str) NCBI accession identifier
  - `Core`: (str) Lasso peptide core sequence
  - `Leader`: (str) Leader peptide sequence
  - `Total Score`: (float) RODEO prediction score
  - `Predicted Ring Size`: (int/float) Predicted macrolactam ring size
  - `Predicted acceptor residue`: (str) Predicted acceptor amino acid

### ubonodin_rnap_inhibition/train.csv and val.csv

- **Format**: CSV with header
- **Content Summary**: Ubonodin variants with enrichment scores for training (6219 samples) and validation (1332 samples).
- **Fields/Columns**:
  - `Sequence`: (str) Mutation descriptor indicating the amino acid substitution(s) relative to the wild-type sequence (e.g., "A7C", "A7CD18P") -- INPUT (auxiliary)
  - `Score`: (float) Enrichment value estimating RNAP inhibitory activity (range approximately -8.9 to 6.0) -- TARGET
  - `Full_Sequence`: (str) Complete 28-residue amino acid sequence of the ubonodin variant -- INPUT (primary)

### ubonodin_rnap_inhibition/test_input.csv

- **Format**: CSV with header
- **Content Summary**: Ubonodin variant sequences for prediction (1334 samples).
- **Fields/Columns**:
  - `Sequence`: (str) Mutation descriptor -- INPUT (auxiliary)
  - `Full_Sequence`: (str) Complete 28-residue amino acid sequence -- INPUT (primary)

## 4. Special Notes

- All amino acid sequences use standard single-letter amino acid codes.
- The labeled `cyclase_peptide_pair` training and validation splits each contain equal numbers of positive and negative pairs, reflecting a balanced binary classification task. The test split is unlabeled.
- In the `ubonodin_rnap_inhibition` instance, all variant sequences are exactly 28 amino acids long. The `Sequence` column provides a human-readable mutation descriptor but `Full_Sequence` is the primary input for computational approaches.
- The `RODEO_seq_high_score.xlsx` file is identical in both instances and may be used for domain-adaptive pretraining of language models on lasso peptide sequences.

## 5. Empirical EDA Addendum

| Instance and split | Rows | Input length summary | Target summary |
|---|---:|---|---|
| Cyclase pair train / validation / test | 9,238 / 1,980 / 1,980 | Cyclase medians 613 / 612 / 613 aa; core median 20 aa in all splits | Train 4,619/4,619 and validation 990/990 for labels 0/1 |
| Ubonodin train / validation / test | 6,219 / 1,332 / 1,334 | `Full_Sequence` is 28 aa throughout; mutation descriptor median length is 8 characters | Score medians -4.714 / -4.743 / unavailable |

Cyclase/core pairs have zero exact overlap among train, validation, and test. Ubonodin has no train–validation or validation–test pair overlap, but one training pair appears in test, so leakage-sensitive diagnostics should account for it. Ubonodin training scores span -8.891 to 5.993 and are strongly skewed toward negative values; the 10th and 90th percentiles are -6.353 and 2.161. Most mutation descriptors encode two substitutions (4,685 of 6,219), followed by three substitutions (1,291).

The two copies of `RODEO_seq_high_score.xlsx` are byte-identical and should be treated as one shared pretraining resource. The downstream tasks remain fundamentally different: balanced pair classification for cyclase compatibility versus continuous activity regression for ubonodin variants.
