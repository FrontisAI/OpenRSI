## 2. Dataset Overview

This dataset covers variant effect prediction (VEP) across two biological domains: coding variants in cardiovascular diseases and non-coding variants affecting RNA splicing regulation. The goal is to classify genetic variants as pathogenic or benign based on sequence information.

The coding VEP domain includes four instances. The `cm_rare_variant` and `arm_rare_variant` instances contain rare missense variants for cardiomyopathy (CM) and arrhythmias (ARM) respectively, represented as paired protein sequences (wild-type and mutant). The `clinvar_cm` and `clinvar_arm` instances contain broader sets of CM- and ARM-associated missense variants derived from ClinVar clinical annotations. The ClinVar instances share their training data with the corresponding rare-variant instances but present a more challenging evaluation scenario with variants drawn from a wider gene set.

The non-coding VEP domain includes two instances. The `mfass_splicing` instance contains variants from a multiplexed functional assay of splicing (MFASS), represented as paired DNA sequences. The `clinvar_splicing` instance contains ClinVar-derived splicing-related variants and follows a two-step training paradigm: initial training on the MFASS data, followed by fine-tuning on the ClinVar splicing training split. Both `clinvar_cm`/`clinvar_arm` and `clinvar_splicing` represent generalization scenarios where models must transfer learned patterns to independent, clinically annotated variant sets.

There are cross-instance dependencies: `clinvar_cm` depends on a model first trained on `cm_rare_variant` data; `clinvar_arm` depends on a model first trained on `arm_rare_variant` data; and `clinvar_splicing` depends on a model first trained on `mfass_splicing` data before fine-tuning its classification head on the ClinVar splicing training split.

## 3. File Formats & Schemas

### Protein Sequence Files (cm_rare_variant, arm_rare_variant, clinvar_cm, clinvar_arm)

#### Training Files: `cm_train_data_1024.csv`, `arm_train_data_1024.csv`

- **Format**: CSV with header row
- **Content Summary**: Paired wild-type and mutant protein sequences for rare missense variants in cardiovascular diseases, with mutation position and pathogenicity labels.
- **Fields/Columns**:
  - `wt_seq`: String, wild-type protein amino acid sequence (length 52-1022 residues) -- INPUT
  - `mut_seq`: String, mutant protein amino acid sequence with a single missense substitution -- INPUT
  - `start_pos`: Integer, position index of the mutation relative to the sequence window (can be negative for N-terminal truncated windows) -- INPUT
  - `labels`: Integer (0 or 1), pathogenicity label where 1 = pathogenic and 0 = benign -- TARGET

#### Test Input Files: `x_test.csv` (cm_rare_variant, arm_rare_variant)

- **Format**: CSV with header row
- **Fields/Columns**:
  - `wt_seq`: String, wild-type protein sequence -- INPUT
  - `mut_seq`: String, mutant protein sequence -- INPUT
  - `start_pos`: Integer, mutation position index -- INPUT

#### Test Input Files: `x_test.csv` (clinvar_cm, clinvar_arm)

- **Format**: CSV with header row
- **Content Summary**: ClinVar-derived missense variants; note that these files do not contain a `start_pos` column.
- **Fields/Columns**:
  - `wt_seq`: String, wild-type protein sequence -- INPUT
  - `mut_seq`: String, mutant protein sequence -- INPUT

### DNA Sequence Files (mfass_splicing, clinvar_splicing)

#### Training and Validation Files: `mfass_train.csv`, `mfass_val.csv`, `clinvar_train.csv`, `clinvar_val.csv`

- **Format**: CSV with header row
- **Content Summary**: Paired DNA sequences representing wild-type and variant genomic regions around splice sites, with binary labels indicating splice-disrupting effects.
- **Fields/Columns**:
  - `seq_a`: String, reference DNA sequence (MFASS: exactly 170 bp; ClinVar: exactly 200 bp in the visible files) -- INPUT
  - `seq_b`: String, variant DNA sequence; MFASS pairs contain one nucleotide substitution, whereas ClinVar includes substitutions, indels, and a small number of stored pairs with no literal sequence difference -- INPUT
  - `labels`: Integer (0 or 1), splice disruption label where 1 = splice-disrupting and 0 = non-disrupting -- TARGET

#### Test Input Files: `x_test.csv` (mfass_splicing, clinvar_splicing)

- **Format**: CSV with header row
- **Fields/Columns**:
  - `seq_a`: String, reference DNA sequence -- INPUT
  - `seq_b`: String, variant DNA sequence -- INPUT

## 4. Special Notes

- **Protein sequence length constraint**: The coding VEP training files use a 1024 amino acid length filter (indicated by the `_1024` suffix), meaning proteins longer than 1024 residues have been excluded. Protein sequences in the data range from 52 to 1022 residues.
- **Column schema differences across instances**: The rare-variant protein instances (`cm_rare_variant`, `arm_rare_variant`) include a `start_pos` column in both training and test files, while the ClinVar protein instances (`clinvar_cm`, `clinvar_arm`) do not include `start_pos`. Models must handle this schema difference.
- **DNA sequence lengths**: Both MFASS sequence columns are uniformly 170 bp. In ClinVar, `seq_a` is uniformly 200 bp, but `seq_b` is variable-length because the visible data include indels as well as substitutions.
- **Class imbalance**: All instances exhibit class imbalance. In coding VEP instances, the imbalance is moderate (roughly 55-68% majority class). In non-coding VEP instances, the imbalance is severe: MFASS training has approximately 96% non-disrupting variants, and ClinVar splicing training has approximately 96% benign variants.
- **Cross-instance training dependency**: The `clinvar_cm` instance does not include a pretrained model; one must be obtained by first training on the `cm_rare_variant` training data. Similarly, `clinvar_arm` requires a model trained on `arm_rare_variant` data. The `clinvar_splicing` instance requires a model first trained on the MFASS data (provided within its directory), followed by classification head training on its ClinVar training split.

| `clinvar_splicing` | 541,920 train + 67,740 validation | 67,740 | 3.60% train; 3.62% validation | `seq_a` is 200 bp; `seq_b` spans 102–10,803 bp in train, 103–7,888 in validation, and 103–7,569 in test |

The CM and ARM training resources are byte-identical across their rare-variant and ClinVar directories, as are the duplicated MFASS train/validation files. These are shared transfer-learning inputs, not additional independent observations. The severe positive-class imbalance in both splicing tasks makes accuracy uninformative without class-aware metrics. ClinVar `seq_b` also contains `N` and `.` characters in addition to canonical A/C/G/T; tokenization and length handling must be robust to these records. Literal `seq_a`/`seq_b` equality occurs in 1,940 ClinVar training, 261 validation, and 249 test rows and should be retained as an observed data case.
