## 2. Dataset Overview

This dataset contains deep mutational scanning (DMS) data for 11 protein function prediction tasks spanning 8 distinct proteins. Each instance corresponds to a specific protein and a specific functional property measured experimentally. The proteins vary substantially in size (56 to 403 residues), structural fold, and biological function, providing a diverse benchmark for sequence-function prediction methods.

Each instance consists of protein sequence variants described by their amino acid substitutions relative to a wild-type reference sequence, along with experimentally measured functional scores. The functional scores have been log-transformed and normalized such that the wild-type score equals zero. Negative scores indicate reduced function compared to wild type, and positive scores indicate enhanced function. The variants contain between 1 and 11 amino acid substitutions, and the data originate from high-throughput deep mutational scanning experiments.

For proteins with multiple measured properties (DLG4, GRB2, PTEN), separate instances are provided for each property. DLG4 and GRB2 each have abundance and binding measurements, while PTEN has abundance and enzymatic activity measurements. These instances for the same protein share the same protein structure file but have distinct variant sets and functional scores.

Each instance also includes a PDB protein structure file for the wild-type protein. These structures are sourced from the RCSB Protein Data Bank or the AlphaFold Protein Structure Database and can be used for structure-aware modeling approaches.

## 3. File Formats & Schemas

### TSV Data Files (train.tsv and test.tsv)

- **Format**: Tab-separated values (TSV), with a header row.
- **Content Summary**: Each row represents a protein sequence variant with its amino acid substitutions and associated information.

**train.tsv columns:**
- `variant` (string): Amino acid substitutions relative to wild type, formatted as comma-separated single-letter mutations with position indices. Single mutations use the format `{original_AA}{position}{mutant_AA}` (e.g., `K1E`). Multi-site mutations are comma-separated (e.g., `A2G,K3R`). Positions use zero-based indexing. INPUT.
- `num_mutations` (integer): Number of amino acid substitutions in this variant (range: 1-11). INPUT.
- `score` (float): Experimentally measured functional score, log-transformed and normalized (wild-type = 0). Rounded to 7 decimal places. TARGET.

**test.tsv columns:**
- `variant` (string): Same format as train.tsv. INPUT.
- `num_mutations` (integer): Same format as train.tsv. INPUT.

### PDB Structure Files

- **Format**: Protein Data Bank (PDB) text format.
- **Content Summary**: Three-dimensional atomic coordinates for the wild-type protein structure. Contains ATOM records with atomic positions for standard amino acid residues. Some files originate from experimental crystallography/NMR (PDB identifiers such as 1gfl, 2qmt, 6qji), while others are AlphaFold-predicted structures (filenames prefixed with `AF-`).

## 4. Special Notes

- The `variant` field uses a comma (`,`) as the delimiter between multiple mutations within a single variant (e.g., `A2G,K3R` denotes two simultaneous substitutions at positions 2 and 3).
- The variant position indexing is zero-based (the first residue is position 0).
- The `score` column is present in train.tsv but absent from test.tsv. The task is to predict scores for test variants.
- Dataset sizes vary substantially across instances, from 3,948 training variants (pten_abundance) to 482,475 training variants (gb1). This range should be considered when designing methods that may need to generalize across different data scales.
- The DLG4 instances (dlg4_abundance and dlg4_binding) share the same PDB structure file, as do the GRB2 instances (grb2_abundance and grb2_binding) and the PTEN instances (pten_abundance and pten_activity). However, each instance has independent training and test data.

No exact variant string is shared between train and test within any instance. Mutation-token parsing found no malformed tokens in the visible tables. Assays sharing a protein are not independent at the sequence level: DLG4 abundance/binding share 4,431 training variants, GRB2 abundance/binding share 4,316, and PTEN abundance/activity share 3,073. Their structures can be reused, but endpoint-specific validation must be retained. Score ranges differ sharply across assays, so regression targets should be standardized and evaluated per instance rather than pooled.
