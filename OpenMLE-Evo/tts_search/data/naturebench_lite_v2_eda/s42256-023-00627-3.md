# Data Description

## 1. Directory Structure

```
data/
├── ibd/                              # Inflammatory bowel disease cohort (external validation)
│   ├── microbiome_PRISM.csv          # Training microbiome profiles (200 taxa x 155 samples)
│   ├── metabolome_PRISM.csv          # Training metabolome profiles (8,848 metabolites x 155 samples)
│   ├── metabolome_annotation.csv     # Annotation for 466 annotated metabolites
│   ├── diagnosis_PRISM.csv           # Diagnosis labels for 155 training samples
│   └── microbiome_external.csv       # Test microbiome profiles (200 taxa x 65 samples)
├── cystic_fibrosis/                  # Cystic fibrosis lung sputum samples
│   ├── microbiome_train.csv          # Training microbiome profiles (1,119 features x 137 samples)
│   ├── metabolome_train.csv          # Training metabolome profiles (168 metabolites x 137 samples)
│   └── microbiome_test.csv           # Test microbiome profiles (1,119 features x 35 samples)
└── soil/                             # Desert soil biocrust samples
    ├── microbiome_train.csv          # Training microbiome profiles (466 taxa x 15 samples)
    ├── metabolome_train.csv          # Training metabolome profiles (85 metabolites x 15 samples)
    └── microbiome_test.csv           # Test microbiome profiles (466 taxa x 4 samples)
```

## 2. Dataset Overview

This dataset contains paired microbiome composition and metabolomic profiles from three distinct microbial environments: human gut (inflammatory bowel disease cohorts), human lung (cystic fibrosis patients), and desert soil (biocrust samples). Each instance provides microbial community profiles alongside corresponding metabolomic measurements, enabling prediction of metabolomic profiles from microbial composition data. The IBD microbiome is on a relative-abundance scale, whereas the cystic-fibrosis and soil microbiome matrices are count-like and must not be interpreted as proportions.

The three instances differ substantially in scale and domain. The IBD instance has the largest metabolome dimension (8,848 metabolites) relative to its microbiome dimension (200 taxa), with training and test data drawn from independently collected cohorts. The cystic fibrosis instance has the opposite ratio, with a much larger microbiome feature space (1,119 features) and a smaller metabolome (168 metabolites). The soil instance is the smallest, with 466 taxa, 85 metabolites, and only 19 total samples.

## 3. File Formats & Schemas

All files are in CSV format with the first column serving as the row index.

### Microbiome Profiles (`microbiome_*.csv`)

- **Format**: CSV with header row and index column
- **Content Summary**: Microbial feature profiles across samples. Rows represent taxa or microbial features and columns represent samples. IBD values are relative abundances; cystic-fibrosis and soil values are count-like.
- **Fields**:
  - Row index: Taxon identifiers (species names for IBD, taxonomic strings for cystic fibrosis, gene marker identifiers with phylum annotations for soil)
  - Column headers: Sample identifiers
  - Values: non-negative numeric measurements; IBD values lie on a relative-abundance scale, while cystic-fibrosis and soil values extend well above 1 and are count-like

### Metabolome Profiles (`metabolome_*.csv`)

- **Format**: CSV with header row and index column
- **Content Summary**: Metabolite concentration profiles across samples. Rows represent metabolites, columns represent samples.
- **Fields**:
  - Row index: Metabolite identifiers (cluster-based IDs for IBD, metabolite names for cystic fibrosis and soil)
  - Column headers: Sample identifiers (matching corresponding microbiome files)
  - Values: `float64`, metabolite concentrations (non-negative)

### Metabolome Annotation (`metabolome_annotation.csv`, IBD instance only)

- **Format**: CSV with header row and index column
- **Content Summary**: Maps 466 annotated metabolites to their chemical identities. Only metabolites present in this file are annotated; the remaining metabolites in the full metabolome are unannotated.
- **Fields**:
  - `Metabolomic Feature` (index): Metabolite identifier matching rows in the metabolome profiles
  - `Retention Time`: `float64`, chromatographic retention time
  - `m/z`: `float64`, mass-to-charge ratio
  - `Compound Name`: `str`, chemical compound name
  - `Adduct`: `str`, adduct ion form

### Diagnosis Labels (`diagnosis_PRISM.csv`, IBD instance only)

- **Format**: CSV with header row and index column
- **Content Summary**: Disease status for each training sample.
- **Fields**:
  - Row index: Sample identifiers matching microbiome/metabolome columns
  - `0`: `str`, diagnosis category ("IBD" or "Healthy")

## 4. Special Notes

- **Data orientation**: In all microbiome and metabolome CSV files, rows represent features (taxa or metabolites) and columns represent samples. This is transposed relative to the common convention where rows are samples.
- **IBD annotation filtering**: The IBD instance contains 8,848 metabolites in total, of which only 466 are annotated (listed in `metabolome_annotation.csv`). Evaluation metrics are computed only on the annotated metabolites.
- **Sample alignment**: Within every visible instance, the training microbiome and metabolome columns match exactly by sample ID and order. The test microbiome uses the same feature index as its corresponding training microbiome. Alignment should nevertheless be checked explicitly rather than inferred from position.
- **Scale differences**: Metabolite concentrations vary substantially across instances. IBD metabolome values range from 0 to approximately 385,626; cystic fibrosis and soil metabolome values are on different scales. No pre-normalization has been applied.

## 5. Empirical EDA Addendum

Matrices were read with the first CSV column as the feature/sample index, so the shapes below exclude that index column.

| Instance | Microbiome train | Metabolome train | Microbiome test | Microbiome zero fraction | Metabolome zero fraction | Median standardized train/test taxon shift |
|---|---:|---:|---:|---:|---:|---:|
| `ibd` | 200 × 155 | 8,848 × 155 | 200 × 65 | 61.21% | 28.70% | 0.176 |
| `cystic_fibrosis` | 1,119 × 137 | 168 × 137 | 1,119 × 35 | 96.69% | 61.56% | 0.096 |
| `soil` | 466 × 15 | 85 × 15 | 466 × 4 | 49.26% | 0.39% | 0.402 |

For all three instances, training sample IDs match between the microbiome and metabolome matrices, and the test microbiome feature index exactly matches the training feature index. IBD microbiome column sums are close to one (training median 0.993; test median 0.969), while cystic-fibrosis and soil medians are 73,382 and 21,752, confirming that those two inputs are count-like. Metabolome scales are also incomparable: maxima are 385,626 for IBD, 44.24 million for cystic fibrosis, and 3.744 billion for soil.

Only 466 of the 8,848 IBD metabolite rows (5.27%) have entries in `metabolome_annotation.csv`; all 466 identifiers match the metabolome matrix. The visible diagnosis file contains 121 IBD and 34 healthy training samples. Normalization, feature filtering, and validation must therefore be instance-specific, with especially cautious uncertainty estimates for the 15-sample soil training set.
